- VAT rate is typically 0.15 (15%) in Saudi Arabia
- If a field is not present in the invoice, use null
- For Arabic text, preserve original Arabic in description fields
- vat_number must be digits only (remove spaces/dashes)
- invoice_date must be YYYY-MM-DD (convert from Hijri or DD/MM/YYYY if needed)
- For line items: if the invoice has a single column combining name and description (e.g. "Yearly Services\nTechnical support for ERPNext"), split on the first newline, period, or colon — first part becomes item_name, remainder becomes description
- item_name should be the short product code or service name (first line); description should be the full text
- uom: extract from the invoice if shown (e.g. "Hours", "Month", "Kg"); otherwise default to "Nos"
